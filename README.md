This repo has my AI lab work. There are 5 labs in it.

Lab 1 is about conditions in python and a small dynamic calculator program.
Lab 2 has fizzbuzz, a movie budget program and a small oop example.
Lab 3 is a model based reflex agent for a heater and an ac.
Lab 4 is A star search, I have also compared it with ucs in it.
Lab 5 is minimax and alpha beta pruning on a small game tree.

Every lab folder has its python file and a word file with it. The word file in the main folder (AI_Lab_Explanation) explains labs 1 to 3.

To run a program, open the lab folder and run its python file from there, like this:
python lab1_conditions_calculator.py
